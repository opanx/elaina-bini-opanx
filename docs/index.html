🚀 Quick Start

Prerequisites

  • Node.js 20 or higher
  • npm or yarn
  • WhatsApp account
  • Pterodactyl Panel (or VPS)
1

Clone Repository

git clone https://github.com/opanx/elaina-bini-opanx.git
cd elaina-bini-opanx
2

Install Dependencies

npm install
3

Setup Configuration

cp .env.example .env
nano .env  # Edit with your settings
4

Start Bot

# QR Code mode
node src/index.js

# Pairing Code mode (no QR needed)
node src/index.js --pairing --phone 628xxxxxxxxxx

🖥️ Deploy on Pterodactyl

💡 What is Pterodactyl?
Pterodactyl is an open-source game server management panel. It supports Node.js applications and provides a web-based console, file manager, and auto-restart features.
1

Import Node.js Egg

Download the node.js generic egg from eggs.pterodactyl.io

Then import it to your Pterodactyl admin panel → Nests → Import Egg

2

Create Server

Create a new server using the imported egg:

  • Server Name: Elaina Bot
  • Memory: 512MB - 1GB
  • Disk: 1GB
  • Startup Command: npm install && node src/index.js
3

Upload Source Code

Use the File Manager tab to upload your bot files, or use Git:

# In the console
git clone https://github.com/opanx/elaina-bini-opanx.git .
npm install
4

Configure Environment

Edit the .env file with your settings:

BOT_NAME=Elaina The Primary
OWNER_NUMBER=628xxxxxxxxxx
PREFIX=.
OPENAI_API_KEY=sk-xxxxx
GEMINI_API_KEY=xxxxx
5

Start & Scan QR

Click Start → Open Console → QR code appears → Scan from WhatsApp

✅ Bot is now running 24/7!

🔗 Pairing Code (No QR Needed)

How to Use Pairing Code

Instead of scanning QR code, you can use a pairing code:

# Start with pairing code
node src/index.js --pairing --phone 628xxxxxxxxxx

# Or using short flags
node src/index.js -p -n 628xxxxxxxxxx

Steps:

  1. Run the bot with --pairing flag
  2. Bot will display a 8-digit code
  3. Open WhatsApp → Settings → Linked Devices
  4. Tap "Link with Phone Number"
  5. Enter the code displayed
⚠️ Note: Pairing code works on WhatsApp Android v2.23.24.82+ and iOS v2.23.24.82+
